## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Define and implement a versioned OKC extension for typed document relationships while preserving OKF v0.2 interoperability. Canonical Markdown links remain the portable graph; typed metadata enriches those links for OKC-aware consumers. Unknown relationship types and missing targets remain representable and diagnosable rather than making an otherwise valid OKF document unreadable.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The extension format is versioned, documented, and additive to canonical Markdown links rather than creating a disconnected shadow graph
- [ ] #2 Known relationship types have documented semantics while unknown types are preserved and returned without parse failure
- [ ] #3 Missing typed targets produce validation warnings consistent with OKF broken-link tolerance rather than rejecting the document
- [ ] #4 Typed edges are persisted through a migration that preserves all existing untyped links and supports idempotent rescan
- [ ] #5 Existing get_links, get_backlinks, and traverse interfaces expose optional relationship metadata and filters without changing unfiltered defaults
- [ ] #6 Conflicting typed metadata and Markdown links produce a portability diagnostic with a deterministic resolution rule
- [ ] #7 Tests cover untyped bundles, typed links, unknown types, broken targets, migration, rescan, filtering, and backward-compatible responses
<!-- AC:END -->
